# AIfy-Solutions
Business Automation — marketing site for https://aify.solutions/

A static, dependency-free site with a modern, premium dark design.

- `index.html` — page content (hero, services, process, results, FAQ, contact)
- `styles.css` — design tokens (`:root`) and all styles
- `script.js` — sticky nav, mobile menu, scroll reveals, stat count-up
- `assets/favicon.svg`

Preview locally: open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
Deploy anywhere static (Netlify, Vercel, GitHub Pages) — no build step.
